# Data Detective AI

A schema-agnostic natural-language data analyst.

Users can upload CSV or Excel files, ask business questions in natural language, view calculated answers and charts, and explore automatically discovered insights.

## Modules

- frontend: React user interface
- backend: FastAPI application and integration
- ai-engine: Schema inference and natural-language data analysis
- insight-engine: Anomaly detection and insight generation
- datasets: Sample datasets for testing
